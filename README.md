Proyecto en Python para realizar peticiones a la API de Gemini utilizando google-genai.

Paso a Paso
1. Obtener la API Key:
Entrar a Google AI Studio con una cuenta de Google.
Seleccionar "Get API key".
Crear una nueva clave y copiarla en un lugar seguro.
2. Instalar las librerías:
Abrir la terminal de VS Code.
Ejecutar: pip install google-genai python-dotenv
3. Configurar la clave:
Crear un archivo .env en la carpeta del proyecto.
Agregar: GEMINI_API_KEY=Tu_Clave_Aqui
No compartir ni publicar la API Key.
4. Ejecutar el programa:
Abrir la terminal en la carpeta del proyecto.
Ejecutar: python geminiapi.py
5. Resultado:
El programa se conecta con Gemini.
Envía la consulta al modelo.
Muestra la respuesta generada en la terminal.
